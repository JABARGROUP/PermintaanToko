# Halaman Pengalihan (Redirect) - permintaanToko

Halaman blank putih dengan animasi loading putar yang otomatis mengalihkan pengunjung ke:  
👉 **https://polytasik-pixel.github.io/permintaanToko/**

---

## 📁 Berkas
- **`index.html`** : File utama yang siap diunggah ke repositori GitHub Pages lama.

---

## 🚀 Cara Upload ke GitHub
1. Buka repositori GitHub lama Anda di browser.
2. Klik tombol **`Add file`** > **`Upload files`**.
3. Unggah file **`index.html`**.
4. Klik tombol **`Commit changes`**.
5. Halaman lama sekarang akan langsung menampilkan layar putih + loading putar dan langsung berpindah ke link baru.
